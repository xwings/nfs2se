Need for Speed II SE

The 1997 racer running natively in the browser: WebAssembly with a WebGL2 renderer.

Game files

Looking for imported game files…

Import your own copy of the game: the installed game folder, a CD image (ISO or BIN) or a ZIP archive with its FEDATA and GAMEDATA folders. Drop it here or choose it.

The files stay on this computer, in this browser's storage. Import them once; they are kept for the next visit.

Controls and notes
  • Keyboard and gamepads work as in the original game; change the controls in the game's options.
  • Alt+Enter or the Fullscreen button switches to fullscreen. Move the mouse to show the buttons while playing.
  • Saved games, records and game settings are kept in this browser.
  • Network play is not available in the browser.
